# 主人的流程

这个文件只记录本项目日常运行、检查、排错的常用命令。

## 0. 进入项目目录

```bash
cd "/Users/boqingxin/tandon MSCS/My_Own/financial-data-platform"
```

为什么：后面的 Poetry、Alembic、CLI 命令都要在项目根目录执行。

## 1. 检查 Poetry 环境

```bash
poetry --version
```

做什么：确认本机能找到 Poetry。

```bash
poetry env info
```

做什么：查看当前项目使用的 Python 虚拟环境和 Python 版本。

```bash
poetry run python --version
```

做什么：确认项目虚拟环境里的 Python 版本。

## 2. 安装依赖

```bash
poetry install
```

做什么：按 `pyproject.toml` 和 `poetry.lock` 安装项目依赖。

为什么：保证本机环境和项目锁定依赖一致。

## 3. 准备本机密钥配置

```bash
cp .env.example .env
```

做什么：复制一份本机私密配置模板。

为什么：真实 MySQL 密码和 EODHD API key 只放 `.env`，不要提交到 Git。

`.env` 至少需要这些值：

```env
FDP_DB_HOST=localhost
FDP_DB_PORT=3306
FDP_DB_USER=你的mysql用户名
FDP_DB_PASSWORD=你的mysql密码
FDP_DB_NAME=mysql
EODHD_API_KEY=你的EODHD_API_KEY
```

为什么：`FDP_DB_NAME=mysql` 只是连接 MySQL server 的初始库名，migration 会创建 `us_share`、`a_share`、`system`。

## 4. 检查 CLI 入口

```bash
poetry run fdp --help
```

做什么：确认主控 CLI 能启动。具体命令见下一节。

## 4.1 CLI 命令

当前已经实现的 ingest CLI 有 instrument 清单抓取、指定 symbol 的历史日频抓取、指数历史日频抓取和市场日历抓取。

查看 ingest 子命令：

```bash
poetry run fdp ingest --help
```

查看 instrument 抓取参数：

```bash
poetry run fdp ingest instruments --help
```

查看历史日频抓取参数：

```bash
poetry run fdp ingest history --help
```

查看指数历史日频抓取参数：

```bash
poetry run fdp ingest indices --help
```

查看市场日历抓取参数：

```bash
poetry run fdp ingest calendar --help
```

抓取 US active stock/ETF instrument：

```bash
poetry run fdp ingest instruments --market US --source eodhd
```

指定 EODHD ticker rename 起始日期：

```bash
poetry run fdp ingest instruments --market US --source eodhd --rename-from 2022-07-22
```

注意：如果当前 EODHD key 没有 `/symbol-change-history` 权限，这个命令会先失败在 rename 预处理阶段，不会继续写新的 instrument。

做什么：

```text
读取 .env
连接 MySQL
检查 us_share / system schema
拉 EODHD symbol-change-history
先处理 ticker rename，例如 FB -> META
拉 EODHD exchange-symbol-list/US
解析 active stock/ETF
upsert 到 us_share.instrument
写 system.ingestion_task_run 和 system.api_call_log
```

输出示例：

```text
instrument ingest run_id=123 status=success fetched=9000 accepted=8000 rejected=0
```

抓取指定 symbol 的历史日频 OHLCV：

```bash
poetry run fdp ingest history --market US --source eodhd --symbols AAPL,MSFT,SPY --from 2023-01-01 --to 2024-01-01
```

做什么：

```text
读取 .env
连接 MySQL
检查 us_share / system schema
按当前 symbol 查 us_share.instrument
调用 EODHD /eod/{provider_symbol}
解析并校验 OHLCV
按 asset_type upsert 到 us_share.stock_daily_price / us_share.etf_daily_price
写 system.ingestion_task_run 和 system.api_call_log
```

输出示例：

```text
history ingest run_id=124 status=success symbols=3/3 fetched=753 inserted=753 rejected=0
```

注意：history 抓取依赖 `us_share.instrument` 里已经存在对应的当前 `symbol` 和 `provider_symbol`。

抓取常用美股指数 3 年日频 OHLCV：

```bash
poetry run fdp ingest indices --from 2023-01-01 --to 2025-12-31
```

默认抓这些 EODHD index provider symbols：

```text
GSPC.INDX, DJI.INDX, IXIC.INDX, NDX.INDX
```

做什么：

```text
确保 index instrument 存在于 us_share.instrument
调用 EODHD /eod/{provider_symbol}
解析并校验 OHLCV
upsert 到 us_share.index_daily_price
写 system.ingestion_task_run 和 system.api_call_log
```

输出示例：

```text
index history ingest run_id=125 status=success symbols=4/4 fetched=3009 inserted=3009 rejected=0
```

抓取 US 市场日历：

```bash
poetry run fdp ingest calendar --market US --source eodhd --from 2023-01-01 --to 2025-12-31
```

做什么：

```text
调用 EODHD legacy exchange-details/US 获取多年 official holidays
按自然日生成 calendar_date / is_trading_day / source
upsert 到 us_share.market_calendar
写 system.ingestion_task_run 和 system.api_call_log
```

验证 split daily price tables：

```bash
poetry run fdp validate daily-price --from 2023-01-01 --to 2025-12-31 --asset-types stock,etf,index
```

做什么：

```text
读取 .env
连接 MySQL
检查 us_share / system schema
依次检查 stock_daily_price / etf_daily_price / index_daily_price
检查 duplicate instrument_id + trade_date
检查已加载 instrument 的 trading-day 缺失行
检查 OHLCV 基础合法性
检查非交易日价格行
写 system.data_quality_check_run 和 system.data_quality_issue
```

输出示例：

```text
daily-price validate status=success date_from=2023-01-01 date_to=2025-12-31 issues=0
  check_run_id=13 table=stock_daily_price asset_type=stock issues=0
```

EODHD API 临时失败时，CLI 会显示 `retrying`、endpoint、错误信息和等待秒数。默认最多重试 3 次，每次等待 30 秒。

状态说明：

```text
success：全部解析成功。
partial_failed：部分行被拒绝，例如 unsupported asset type、inactive instrument、字段缺失。
failed：API、配置、数据库 schema 等关键步骤失败。
```

```bash
poetry run fdp ingest daily ...
poetry run fdp repair ...
```

## 5. 检查 Alembic migration

```bash
poetry run alembic heads
```

做什么：确认 Alembic 能看到当前最新 migration。

为什么：它只检查 migration 文件，不连接数据库、不建表，是安全预检查。

预期为：

```text
0006_split_daily_tables (head)
```

## 6. 创建或升级数据库结构

```bash
poetry run alembic upgrade head
```

做什么：把 migration 应用到 MySQL。

为什么：这一步会创建 `us_share`、`a_share`、`system` schema 和当前所有表。

## 7. 抓取美股 instrument 列表

```bash
poetry run fdp ingest instruments --market US --source eodhd
```

做什么：调用 EODHD Exchange Symbols，解析 active stock/ETF，并写入 `us_share.instrument`。

为什么：后续价格表需要先通过 `instrument` 找到 `instrument_id`。

## 8. 用 SQL 检查写入结果

```sql
SELECT COUNT(*) FROM us_share.instrument;
```

做什么：看 instrument 表里有多少标的。

```sql
SELECT 'stock_daily_price' AS table_name, COUNT(*) FROM us_share.stock_daily_price
UNION ALL SELECT 'etf_daily_price', COUNT(*) FROM us_share.etf_daily_price
UNION ALL SELECT 'index_daily_price', COUNT(*) FROM us_share.index_daily_price;
```

做什么：看 v0.1 split daily price tables 的行数。

```sql
SELECT *
FROM system.ingestion_task_run
ORDER BY run_id DESC
LIMIT 5;
```

做什么：看最近几次 ingest 任务状态。

```sql
SELECT *
FROM system.api_call_log
ORDER BY api_call_id DESC
LIMIT 5;
```

做什么：看最近几次 EODHD API 调用摘要。

## 9. 跑单元测试

```bash
poetry run pytest
```

做什么：运行 `tests/` 下的自动测试。

为什么：确认 parser、upsert、schema metadata、CLI、ingestion service 的逻辑没有坏。

## 10. 跑代码静态检查

```bash
poetry run ruff check .
```

做什么：检查 Python import、未使用变量、基础风格和常见静态错误。

为什么：它不验证业务逻辑，但能快速抓出低级代码问题。

## 11. 提交前建议检查组合

```bash
poetry run pytest
poetry run ruff check .
poetry run alembic heads
```

做什么：提交前确认测试通过、代码干净、migration 能被识别。

为什么：这三项覆盖了当前阶段最重要的本地健康检查。

## 12. 常见失败含义

```text
ValueError: FDP_DB_USER is required
```

意思：`.env` 里缺少 `FDP_DB_USER`。

```text
missing required database schema(s): us_share, system
```

意思：还没有跑 `poetry run alembic upgrade head`。

```text
EODHD_API_KEY is required
```

意思：`.env` 里缺少 `EODHD_API_KEY`。
