Mac local research utility

EODHD API Code Generator

A lightweight local app for generating EODHD URLs, Python, curl, and JavaScript snippets, executing small research queries, and exporting CSV results without sending your API token to a hosted server.

Download DMG Download PKG Checksums

Developer build: unsigned and not notarized. Production public distribution should use Apple Developer ID signing and notarization.

Install Locally

  1. Download the DMG from this page after running the packaging script.
  2. Open the DMG and drag the app into Applications, or install the PKG.
  3. Launch the app and save your EODHD token through Login / Config.

What Runs On Your Mac

The app starts a local server bound to 127.0.0.1 with a random port and opens it in your browser. It bundles the app source and Python package dependencies, but still requires Python 3.11+ on the Mac.
