# Frontend Guidelines

The public frontend belongs to `database_app`. Read its AGENTS, PROJECT, and
technical design before changing the request builder or static product site.

## Pre-Development Checklist

- [Quality checks](quality-guidelines.md)
- `database_app/docs/TECHNICAL_DESIGN.md`

## Quality Check

Preserve confirmed-request semantics, keyboard access, mobile layout, token
redaction, and export correctness. Run app tests and static boundary checks.
