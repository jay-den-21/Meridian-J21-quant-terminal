# Public Source Release

## Scope

Publish the original US CLI, CN CLI, and EODHD API App under MIT. Retain upstream
licenses for bundled development tooling and inert reference archives. Exclude
private websites, terminal applications, research, vendor PDFs, credentials, and
datasets from every published branch/tag. Preserve excluded local files and an
offline recovery copy; do not call data providers or write databases.

## Acceptance

- A fresh checkout runs documented offline checks in separate component environments.
- All published refs pass secret, excluded-path, and artifact checks.
- Documentation matches the three public products and separates source/data rights.
- Remote history cleanup and public visibility are distinct gates. Residual private
  content access blocks visibility changes until resolved.
